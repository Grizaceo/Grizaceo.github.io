How I build

Three rules run through every project

Abstain when the evidence is missing.

Diké refuses an ambiguous or nonexistent citation instead of guessing which law was meant. The graph search engine abstains when its evidence coverage is low.

In Diké and the graph search engine

Tie every claim to its source.

Each verified article carries the SHA-256 hash of its exact text and the dated corpus it came from, so anyone can see which copy of the law was checked.

In Diké, Diké Shield and the graph search engine

Let someone else check.

Diké's signatures verify with code that is not Diké's. In KISS, a supervisor the model cannot touch runs the tests that decide which code survives.

Diké

Statutory citation verification with signed commitments

Diké reads a Chilean legal brief, finds every statutory citation and checks it against a local, hash-identified snapshot of the law. It certifies only what it can prove. For the citations it verified, it can emit a small Ed25519-signed commitment that anyone can check offline.

  • 25 statutes and 8,544 articles from Ley Chile (Biblioteca del Congreso Nacional), named by a pack hash
  • Runs offline, in a Docker image with the network disabled
  • 552 tests, plus a mutation battery and a differential search across three verifiers
  • Two verification paths that share no code with Diké: a standalone Python script, and jq with OpenSSL

What it does not claim: that an article supports the argument made in the brief. That remains the lawyer's judgment, and the commitment says so in its own fields.

Diké Shield

Citation oversight for an LLM legal assistant

An agent that sits between NVIDIA Nemotron and a labour lawyer. The model drafts an answer on dismissal or severance, and Diké checks every citation in it. Whatever Diké cannot prove is repaired with a verified article, withdrawn with a reason, or escalated. The loop never reinterprets Diké's verdict.

  • Two model lanes, a fast one and a deep one, each tested with and without the shield
  • An adversarial bank of synthetic questions that counts invented citations per lane
  • Refuted citations are remembered across sessions (H-MEM), so they are not repeated
  • The final answer carries a signed commitment for the citations that survived

Graph-based legal search

Chilean environmental law as a knowledge graph

A legal search engine built on a knowledge graph. Every relation between statutes, articles and court decisions carries its evidence: the exact source fragment, its character offset, a SHA-256 hash and a confidence level. Extraction is conservative and fails closed, and each edge records whether a person validated it.

  • 661 automated tests
  • Python, FastAPI, SQLite and a hardened Docker image
  • 11 architecture decision records
  • Personal-data redaction that keeps character offsets, so evidence hashes stay verifiable

KISS Discovery Engine

A code-writing agent that cannot grade itself

A language model (Mercury 2.5) proposes algorithms. Each attempt runs in its own CreateOS microVM fork, where a root-owned supervisor runs 60 hidden tests and timing benchmarks. The winner's paused VM is forked again for the next revision, with the measured feedback.

  • Candidate code is checked on the host only as a syntax tree, never imported or run there
  • 11 real runs audited read-only; all 34 microVMs verified destroyed

Agent infrastructure

Context, memory, audit and voice for my own agents

Smaller systems I built while running my own AI agents day to day. Private repositories are available on request.

SkillRAE

Private

An independent, standard-library-only Python implementation of the SkillRAE paper, whose authors published no code, with parts adapted from SkillCorpus. Given a task and a library of SKILL.md files, it picks the few skills that matter and compiles them into a compact context for the agent.

Ranking is deterministic and every score is broken down, so each choice can be audited. A safety check keeps suspicious skills out of the context and lists them for human review. It runs daily on a personal library of about 900 skills. Measuring whether it helps is still open work, and there is no public benchmark yet.

Agentic Memory Bus

Private

One provenance-aware interface over an agent's different memory stores, ranked by relevance, recency and authority. Consolidation writes a new store, never edits its input, and reports conflicts explicitly.

MR. Robot Adversarial

Public

A security-triage agent built for the SANS FIND EVIL! Hackathon. A second model from a different family audits the first, and a deterministic orchestrator with no LLM makes the final routing decision.
